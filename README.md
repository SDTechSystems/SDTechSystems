# SD Tech Systems

Software para administrar negocios, trabajar con IA local y ofrecer servicios en la web. SD Tech Systems desarrolla aplicaciones y sitios a medida, con atención a la operación diaria, la privacidad y la accesibilidad.

[Conocer los proyectos y probar las demos](https://sdtechsystems.github.io/portfolio/)

## Proyectos

- [OpenMultiPOS](https://github.com/SDTechSystems/OpenMultiPOS): ventas, inventario y administración de varios negocios sobre ERPNext.
- [EasyDrink](https://github.com/SDTechSystems/EasyDrink): punto de venta con almacenamiento local, español e inglés y moneda colombiana.
- Akashic Vault: asistentes de IA locales para Windows con historial cifrado y generación de contenido según la edición.
- Akashic TV: catálogo de películas y series para televisores Samsung Tizen.
- Sitios a medida: páginas de presentación e invitaciones digitales con formularios y contenido adaptable a móviles.
- [TaskTone](https://github.com/SDTechSystems/tasktone): aplicación en desarrollo para encargos de audio entre creadores e ingenieros.

El portafolio presenta el alcance y el estado de cada proyecto. Sus demostraciones utilizan datos ficticios para explorar las interfaces.
